# Grid Span

**Import:** `import {GridSpan} from '@astryxdesign/core/Grid';`

## Props

| Prop | Type | Default | Description |
|---|---|---|---|
| `columns` | `number | 'full'` | — | Columns to span; use `'full'` to span the entire row. |
| `rows` | `number` | — | Rows to span. |
| `children` | `ReactNode` | — | Content. |
